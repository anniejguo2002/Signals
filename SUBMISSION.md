# Signal — TinyFish Hackathon Submission

Signal turns a company URL into live competitor intelligence using TinyFish. Compare products, pricing, and positioning with cited sources, explore visual market maps, test hypothetical SaaS launches, and subscribe to weekly competitor briefs.

Start with README.md for setup. Copy .env.example to .env and supply your own TinyFish API key. Build the frontend and start the FastAPI server as documented.

This package contains source code, dependency manifests and lockfile, tests, and setup documentation. Installed dependencies, secrets, databases, subscribers, screenshots, and saved research are intentionally excluded. References in README.md to prior local report IDs and data files describe development verification; those artifacts are not bundled. Use the live Plausible workflow to generate a new report.

Weekly email delivery requires SMTP credentials and a public HTTPS app URL. The sample email is explicitly fictional. Strategy scenarios are hypothetical assumptions, not verified forecasts.
